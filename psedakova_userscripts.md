# Нейротрекер — Пользовательские сценарии

### Группа: 10-И-1

### [Сценарий 1 — Регистрация и авторизация пользователя]

1. Пользователь открывает приложение и выбирает регистрацию.
2. Вводит электронную почту, логин и пароль.
3. Приложение проверяет корректность введённых данных.
4. Если данные некорректны или логин занят, приложение сообщает об ошибке.
5. После успешной регистрации пользователь попадает на главный экран.
6. При повторном входе пользователь вводит свои учётные данные.

### [Сценарий 2 — Создание и управление задачами]

1. Пользователь открывает календарь.
2. Выбирает дату, на которую хочет добавить задачу.
3. Вводит название и описание задачи.
4. Выбирает одну из трёх категорий: «Драйв», «Фундамент» или «Кайф».
5. Сохраняет задачу, после чего она появляется в календаре.
6. Пользователь может изменить задачу, перенести её на другую дату или удалить.
7. После выполнения задачи пользователь отмечает её как завершённую.

### [Сценарий 3 — Отслеживание настроения]

1. Пользователь открывает раздел отслеживания настроения.
2. Выбирает своё текущее настроение.
3. При необходимости добавляет комментарий.
4. Сохраняет запись.
5. Приложение сохраняет результат и добавляет его в историю наблюдений.
6. Пользователь может просматривать предыдущие записи.

### [Сценарий 4 — Начало трёхнедельного спринта]

1. Пользователь начинает новый трёхнедельный спринт.
2. Приложение предлагает пройти начальный опросник.
3. Пользователь отвечает на вопросы о своём состоянии, привычках и продуктивности.
4. Приложение сохраняет ответы и результаты опросника.
5. Пользователь переходит к планированию задач на период спринта.

### [Сценарий 5 — Завершение трёхнедельного спринта]

1. По окончании трёх недель приложение предлагает пользователю пройти итоговый опросник.
2. Пользователь отвечает на вопросы.
3. Приложение сохраняет результаты.
4. Система сопоставляет начальные и итоговые показатели.
5. Пользователь получает информацию об изменениях за время спринта.

### [Сценарий 6 — Просмотр статистики]

1. Пользователь открывает раздел статистики.
2. Выбирает интересующий его спринт или период времени.
3. Приложение отображает статистику выполнения задач, распределения категорий и изменения настроения.
4. Пользователь просматривает графики и сравнивает результаты разных спринтов.
5. Пользователь может вернуться к предыдущим результатам и оценить изменения за несколько периодов.
